# Workout App

## Commit Prefixes
* FEATURE – Adding a new feature, functionality, or module (e.g., TypeORM setup, new API endpoint)
* FIX – Bug fixes or corrections in the code
* CHORE – Project maintenance, tooling, config changes, dependency updates, Docker setup
* STYLE – Code style changes, formatting, lint fixes (no logic changes)
* REFACTOR – Code restructuring or improvements without changing behavior
* TEST – Adding or updating tests
* DOCS – Documentation updates (README, guides, comments)
